# Lumia Portal

Lumia Portal is the gateway to the Lumia ecosystem — a single place to reach the Lumia
Foundation's offerings: real-world asset tokenization, identity verification, wallet
management, cross-chain transfers, market data and ecosystem news.

This repository is the public home of the Portal's release history. The product itself is
developed in a private repository; what ships from it is documented here.

## What's in this repository

| | |
|---|---|
| [CHANGELOG.md](./CHANGELOG.md) | What shipped, and when |
| [Issues](https://github.com/LumiaChain/lumia-portal/issues) | Bug reports and feature requests |
| [Discussions](https://github.com/LumiaChain/lumia-portal/discussions) | Questions, ideas and proposals |

## Areas

Release notes are labelled by the part of the product a change affects.

- **frontend** — the Portal web application
- **backend** — the API behind it
- **admin** — internal operations and moderation tooling

## Reporting an issue

Open an issue using one of the templates. For anything security-sensitive, do not open a
public issue — write to the Lumia team directly.
